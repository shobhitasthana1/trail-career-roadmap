## 01 Why TRAIL
Choosing a career path is confusing. Resources are scattered, roadmaps go stale, and it's hard to know what to actually learn next.
TRAIL fixes that — one clean, interactive space with structured roadmaps, the right skills, and curated resources, so you always know your next step.

## 05 Getting Started

**1. Clone the repository**

```bash
git clone https://github.com/shobhitasthana1/trail.git
```

<details>
<summary>Other ways to clone (SSH / GitHub CLI)</summary>
<br/>

**SSH**
```bash
git clone git@github.com:shobhitasthana1/trail.git
```

**GitHub CLI**
```bash
gh repo clone shobhitasthana1/trail
```

</details>

**2. Move into the project directory**

```bash
cd trail
```

**3. Install dependencies**

```bash
npm install
```

**4. Start the development server**

```bash
npm run dev
```

That's it — you're up and running. 🎉
